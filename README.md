# Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple program that calculates the interest earned or paid on a principal amount over a specific period at a given rate of interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: Initial amount of money
- Rate: Annual rate of interest
- Time: Time period in years

## Example

- Principal: 5000
- Rate: 5%
- Time: 2 years

Simple Interest = (5000 × 5 × 2) / 100

**Simple Interest = 500**

## Technologies Used
- Python

## Output
The calculator displays the simple interest based on the values entered by the user.

## Conclusion
This project demonstrates the basic concept of simple interest calculation using a simple mathematical formula.
